# Personal portfolio

A personal portfolio with a minimal interactive landing page, five written case studies, six shorter project snapshots, a résumé page, original animated walkthroughs, and a separate presentation room. No framework, package install, build service, or external runtime is required.

## Run

Requires Node.js 20 or newer.

```sh
npm start
```

Open `http://127.0.0.1:4173`. The server binds to this machine only. Set `PORT` to use another port.

- Landing page: `/`
- Work index and project snapshots: `/work/`
- Résumé: `/resume/`
- About and contact: `/about/`
- Written cases: `/work/toast-closeout.html`, `/work/toast-cash-drawer.html`, `/work/goto-wallboard.html`, `/work/goto-conversation-intelligence.html`, `/work/cattia.html`
- Presentation room: `/presentations/`
- Toast slide viewer: `/presentation/`

The static HTML can also be opened directly from disk; use the local server for the interactive landing module. For the presentation, use the arrow keys, Page Up/Down, Home/End, or bottom controls. `F` toggles fullscreen. The slide navigator includes 20 core slides and 3 backups. Speaker notes are embedded as hidden `aside.speaker-notes` elements for editing; no separate presenter window is installed.

The presentation fits one viewport when its content fits, and scrolls instead of overlapping or clipping content on narrow, short, zoomed, or enlarged-text viewports. Overflowing slides enter the Tab order: scroll within the slide, or focus it and use Up/Down or Page Up/Down. Left/Right and the bottom arrows still change slides. The slide navigator supports Tab, Shift+Tab, and Escape, makes the background and external home link inert, and returns focus to its opener when closed. A persistent primary heading remains available between slides.

Authored live text has a 12px minimum throughout the website and presentation, including mobile captions, constellation labels, thumbnail captions, and the deck's text-size reduction controls. Native star targets accommodate wrapped labels and keep their collision geometry synchronized with their rendered size. Skip links move keyboard focus to the main content, and routine star focus changes do not trigger competing live-region announcements. This minimum does not modify text embedded in genuine source images or videos; full-resolution images remain available through the image viewer. Browser/DOM checks and unit regressions do not replace manual VoiceOver/Narrator testing or establish complete WCAG conformance.

## Deployment

GitHub Pages serves this project directly from the `main` branch's repository root. `.nojekyll` keeps the HTML, CSS, JavaScript, and media as ordinary static files; the Node server is only for local preview and is not run by the hosting service. Enable **Settings → Pages → Deploy from a branch → main → / (root)**. Subsequent pushes to `main` automatically update the site.

The routes include `/`, `/work/`, `/resume/`, `/about/`, `/presentations/`, `/presentation/`, and the five individual case URLs listed above. Updates become public after their commit is pushed to `main` and the GitHub Pages deployment completes.

`.gitignore` excludes `resources/`, presentation planning documents, restricted font files, local environment files, and dependency directories. Keep these exclusions when committing updates. A public repository exposes every committed file, not just files linked from the homepage. GitHub Pages does not provide password protection for these case studies or the deck.
